## ハードモードで変わること

ハードモードは単に「同じゲームで時計が短くなっただけ」ではありません。プレイヤーの体験とコミュニティの報告によると、このモードは複数の変数を同時に変化させます。

| 変数 | スタンダードモード | ハードモード（コミュニティ報告） |
| --- | --- | --- |
| 回答タイマー | 余裕がある | 明らかに厳しい |
| 単語の長さ | 一般的で短い単語 | 長く、複数音節の単語 |
| 綴りの罠 | 時々 | 頻繁（二重文字、黙字） |
| ブロック報酬 | 標準 | 正解ごとに高め |
| ミスの代償 | 寛容 | 厳しい |
| 推奨ウォームアップ | なし | 5〜10分のパターンドリル |

実用的な結論はこうです。ハードモードは無知よりもためらいを罰します。ハードモードで失敗するプレイヤーのほとんどは、実は単語の綴り方を知っています。ただ時間のプレッシャーの中で固まったり、迷ったり、打ち間違えたりするだけです。それは才能の問題ではなく、鍛えられる問題です。

現在のモードの利用可否やサーバー詳細は、[Rolimons が追跡する Spelling Race ゲームページ](https://www.rolimons.com/game/17664585395)で確認できます。ここではアップデート、プレイヤー数、開発者が管理する個別のプレイスファイルが記録されています。定期的に更新される専用の Hard Mode プレイスも含まれます。

## リストではなくパターンで回答バンクを構築する

静的な「全答え」リストを検索するのは罠です。Spelling Race は頻繁にアップデートされ、Rolimons のデータではこの執筆の数時間以内にも更新されていました。流出したリストはすぐに古くなります。さらに悪いことに、リストを暗記しても、そこに載っていない単語については何も学べません。

パターンバンクのほうが持続します。学ぶ語彙をテーマ別ではなく、綴りの罠別にグループ化しましょう。

| パターンカテゴリ | プレイヤーがつまずく理由 | 練習単語 |
| --- | --- | --- |
| 二重子音 | 1つ足したり落としたりしやすい | accommodate, committee, necessary |
| 黙字 | 文字はあるのに何も発音しない | rhythm, subtle, muscle, guarantee |
| 母音チーム | 正しく聞こえる選択肢が複数ある | receive, achieve, believe, separate |
| -able と -ible の語尾 | 語根の単語に依存する | noticeable, possible, flexible |
| -ance と -ence の語尾 | これも語根に依存する | performance, difference, existence |
| 不規則複数形 | ルールが崩れる | criteria, phenomena, analyses |

毎日15分、これらを手書きしましょう。手書きは脳に文字の順序を符号化させることを強制し、それがまさにハードモードが負荷をかける想起経路です。

## ブロックを失うよくあるミス

| ミス | どんな姿か | 対策 |
| --- | --- | --- |
| 見直しすぎ | すでに正しく綴った単語を打ち直す | 最初の試行を信じる |
| パニック打ち | タイマーが減る中でランダムな文字を打つ | 10%遅くする — 正確さはまだ報われる |

| ランダムな単語リストを勉強 | パターン認識がない | 綴りの罠別に勉強 |

ティルト（イライラ）の問題は現実です。コミュニティの報告は、1つのミスが焦った回答を生み、それがさらなるミスを生む「デススパイラル」を一貫して描写しています。早く気づくことが解決の半分です。
